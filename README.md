# metachurch.uz

Сайт церкви Meta Church (Ташкент). Статический сайт без сборки: HTML + CSS + немного JS.
Перенесён с Figma Sites по макету «Сайт MetaChurch».

## Структура

```
index.html          — главная страница (вся вёрстка)
404.html            — страница «не найдено»
assets/css/style.css — стили (цвета и шрифты — переменные в начале файла)
assets/js/main.js   — анонс трансляции по расписанию + год в подвале
assets/img/         — изображения (WebP) и og.jpg для превью в соцсетях
favicon.png
robots.txt, sitemap.xml
CNAME               — домен для GitHub Pages
.nojekyll           — отключает обработку Jekyll на GitHub Pages
```

## Как поменять контент

- **Тексты, время собраний, адрес** — прямо в `index.html`.
- **Анонс трансляции** — массив `STREAMS` в начале `assets/js/main.js`.
  Плашка появляется за 30 минут до начала (`ANNOUNCE_BEFORE_MIN`) и висит до `end`.
  Ссылка ведёт на `youtube.com/@metachurchuz/live` — YouTube сам открывает текущую
  или ближайшую запланированную трансляцию канала.
- **Фото в ленте** — файлы `assets/img/gallery-1…8.webp` (вертикальные, примерно 3:4).

## Шрифты

В макете заголовки набраны **TT Travels Next**, но на старом сайте стояла Trial-версия —
её нельзя использовать на публичном сайте без лицензии. Сейчас вместо неё бесплатный
**Unbounded** (Google Fonts). Если купить лицензию TT Travels Next у TypeType:

1. Положить файлы `.woff2` в `assets/fonts/`.
2. Добавить `@font-face` в начало `style.css`.
3. Поменять `--font-display` на `"TT Travels Next", …`.

Рукописная надпись «с древним посланием» — шрифт Caveat (вместо Just Breathe).

## Публикация на GitHub Pages

1. Создать репозиторий (например, `metachurch-site`) в аккаунте или организации церкви
   и загрузить туда содержимое этой папки.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Settings → Pages → Custom domain: `metachurch.uz` (файл `CNAME` уже есть).
4. В панели DNS у Eskiz заменить записи:

   | Тип   | Имя | Значение                 |
   |-------|-----|--------------------------|
   | A     | @   | 185.199.108.153          |
   | A     | @   | 185.199.109.153          |
   | A     | @   | 185.199.110.153          |
   | A     | @   | 185.199.111.153          |
   | CNAME | www | `<логин>.github.io`      |

   Старую A-запись `204.69.207.1` (Figma) удалить.
5. Когда GitHub проверит домен (от минут до суток), включить **Enforce HTTPS**.

## После переноса — индексация

1. Добавить сайт в [Google Search Console](https://search.google.com/search-console)
   (подтверждение через TXT-запись в DNS) и отправить `sitemap.xml`.
2. То же в [Яндекс.Вебмастере](https://webmaster.yandex.ru).
3. Через пару дней проверить в Search Console отчёт «Страницы».

## Что исправлено по сравнению со старым сайтом

- Один `<h1>` и один экземпляр контента вместо трёх копий (по одной на каждый брейкпоинт).
- «Meta Church» набрано латиницей (раньше была кириллическая «С»).
- Все кнопки — настоящие ссылки: трансляция, карта, «Прийти на собрание».
- Добавлены `canonical`, `robots.txt`, разметка Schema.org (Church) с адресом и соцсетями.
- Соцсети в подвале на мобильной версии, «YouTube» без обрезки, «Прийти» вместо «Придти».
- Картинки сжаты в WebP: страница весит примерно в 10 раз меньше.
- Страница работает без JavaScript.
